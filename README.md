# Анализ продаж магазина — «Пряники»

**[Открыть интерактивный дашборд](https://arsen4ik6265.github.io/sales-bonus/dashboard.html)**

Учебный проект по JavaScript, который я самостоятельно выполнил по техническому заданию во время обучения в Яндекс Практикуме. Позже проект был дополнен интерактивным дашбордом.

## О проекте

Программа анализирует учебные данные о продажах магазина, рассчитывает финансовые показатели, формирует рейтинг продавцов по прибыли и определяет размер бонусов.

В проекте предусмотрены три набора демонстрационных данных.

## Что реализовано в исходном проекте

- Расчёт выручки с учётом скидок.
- Расчёт прибыли с учётом себестоимости товаров.
- Подсчёт количества продаж.
- Формирование рейтинга продавцов по прибыльности.
- Расчёт бонусов по установленным правилам.
- Определение самых продаваемых товаров.
- Обработка, группировка и сортировка данных на JavaScript.

## Интерактивный дашборд

Для удобного просмотра результатов добавлена отдельная страница с аналитическим отчётом.

В дашборде доступны:

- Общая выручка, прибыль, количество чеков и сумма бонусов.
- Диаграмма рейтинга продавцов.
- Диаграмма популярных товаров.
- Подробная таблица результатов.
- Поиск и сортировка продавцов.
- Переключение между тремя наборами данных.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

Все показатели рассчитываются на основе исходных учебных данных и функций программы.

## Технологии

- HTML5 и CSS3.
- JavaScript.
- Работа с массивами и объектами.
- DOM и обработка событий.
- Анализ, группировка и сортировка данных.
- Визуализация результатов.

## Структура проекта

- `src/main.js` — исходные функции анализа продаж.
- `data/` — три учебных набора данных.
- `index.html` — исходная версия с выводом результатов в консоль браузера.
- `dashboard.html` — интерактивный аналитический дашборд.
